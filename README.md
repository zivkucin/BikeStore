# BikeStore – Full Stack Application

Full-stack application for managing a bike shop, including product browsing, ordering, and payment processing.

---

## Tech Stack

* Backend: ASP.NET Core (.NET)
* Frontend: React
* Database: PostgreSQL
* Payment: Stripe

---

## Features

* User authentication (JWT)
* Product browsing and filtering
* Shopping cart functionality
* Order management system
* Payment integration with Stripe
